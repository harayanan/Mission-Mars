> Financial literacy educational game with Mars colonization theming — 3 progressive versions

- **Type:** Vanilla HTML/CSS/JavaScript — no frameworks, no build process
- **Versions:** V1 (prototype), V2 (modular), V3 (expanded content)

## Game Features

- 8 Mars colonization-themed financial challenges
- Topics: budgeting, investing, risk management, emergency funds
- Score tracking and decision consequences
- Progressive difficulty levels

## Quick Start

Open `V3/index.html` (or any version) in a browser. No build step required.
